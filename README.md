# OIBSIP-WebDev-L1-Portfolio-
💼 My Personal Portfolio Website

📌 Project Overview

This project is a personal portfolio website developed using HTML5 and CSS3. It is designed to showcase my profile, technical skills, projects, and contact information in a simple, professional, and user-friendly way.

The portfolio acts as my digital resume and provides an overview of my journey as a Computer Science Engineering student.

🎯 Project Objective

To create a responsive personal portfolio website that highlights my skills, projects, interests, and contact details using fundamental web development technologies.

🛠️ Technologies Used

- HTML5 – Used to create the structure and content of the website.
- CSS3 – Used for styling, colors, layouts, and responsive design.

✨ Features

- Profile and hero section introducing myself.
- Navigation bar with Home, About, Skills, Projects, and Contact links.
- About Me section describing my background and interests.
- Skills section showcasing technical skills.
- Projects section displaying project information.
- Contact section with personal contact details.
- Footer section.
- Consistent color scheme and typography.
- Responsive layout for desktop and mobile devices.
- Smooth navigation between website sections.

🚀 How to Run the Project

1. Download or clone this GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open the "index.html" file.
4. Right-click and select Open with Live Server.
5. The personal portfolio website will open in your browser.
